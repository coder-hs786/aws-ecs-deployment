# Troubleshooting

## Common Issues

### 1. MongoDB Connection Failed
- Check if MongoDB is running.
- Verify the MongoDB connection string.
- Check EC2 security group settings.

### 2. Application Not Accessible
- Check if the application is running.
- Verify the required port is open in the EC2 Security Group.

### 3. Permission Issues
- Check file/folder permissions.
- Make sure the required user has access.

### 4. Server Issues
- Check EC2 instance status.
- Check application and system logs.
